# Fix Provider Data Quality & Add Free Credits Page

## Current Issues Identified

### 1. Unverified Free Claims (Critical)
Many providers show `free_model_count > 0` but have `probe_status="needs_key"` — meaning their `:free` suffix claims are **never verified**:
- **Z.ai** (2 free), **Google** (2 free), **Cohere** (1 free), **Qwen** (2 free), **SiliconFlow** (3 free), **b.ai** (5 free), **Fireworks** (0 but has credits)
- Only providers with API keys in CI get 1-token probes → false confidence in free tiers

### 2. b.ai Gateway Leakage
b.ai is a **gateway**, not a model provider. Its free tier shouldn't propagate to upstream providers (DeepSeek, etc.). Current migration is partial — "independent evidence" check too permissive.

### 3. Missing Free Credits Category
Providers offering **signup credits** (not free inference):
- **Together AI** ($1-5 credits), **Fireworks** ($1), **Replicate** ($10), **Anyscale** ($5), **Lambda Labs** ($10), **RunPod** ($5-10), **Modal** ($30/mo), **Hugging Face** (free tier + credits), **OpenRouter** (free credits on signup)
- Currently conflated with `free_kind="free_tier"`

### 4. Dead/Error Providers
Several providers have 0 models + `probe_status="error"`: Zuki, Naga, Nscale, GLHF, Targon, Voidai — likely defunct.

---

## Implementation Plan

### Phase 1: Fix Data Quality (Agent Side)
1. **Raise free claim threshold** in `sources/probe.py` & `sources/provider.py`:
   - Don't auto-set `is_free=True` from provider `:free` suffix without probe verification OR secondary source (models.dev, OpenRouter)
   - Demote `byok_required` → `is_free=False` by default (it's not free, just BYOK)
2. **Fix b.ai leakage**: Any model with ONLY b.ai evidence → stays on `p_bai`, never upstream
3. **Add evidence provenance** to Model: `free_evidence_source` enum + timestamp
4. **Mark stale providers**: Auto-set `status="stale"` for providers with 0 models + error probe > N runs

### Phase 2: Free Credits Data Model
Add to `models.py`:
```python
class CreditProvider(BaseModel):
    provider_id: str
    name: str
    signup_bonus_usd: float
    credit_expiry_days: int | None
    models_available: list[str]
    signup_friction: str  # email, phone, github, trial_card
    homepage: str
    notes: str
```

### Phase 3: Web UI — New `/credits` Page
- Create `apps/web/app/credits/page.tsx` (server component)
- Create `apps/web/components/credits-table.tsx` (client component with filters)
- Add nav link in `site-header.tsx`
- Table columns: Provider | Signup Bonus | Expiry | Models | Friction | Notes

### Phase 4: Seed Credit Providers
Add to `catalog.py` a new `CREDIT_PROVIDERS` list with verified data:
- Together AI ($5, 30 days), Fireworks ($1, 30 days), Replicate ($10, no expiry), Anyscale ($5, 30 days), Lambda Labs ($10, 30 days), RunPod ($5, 30 days), Modal ($30/mo), Hugging Face (free tier + $10), OpenRouter ($1-5)

### Phase 5: Refresh & Verify
Run agent after changes to regenerate `snapshot.json` with corrected data.

2. **Credit provider list**: Should I include providers that require credit card (trial_card) like Cohere, or only email/phone/github signup?
